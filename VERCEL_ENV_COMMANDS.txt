CLI alternative (interactive):
1) Install & login with the Vercel CLI:
   npm i -g vercel
   vercel login

2) Run for each variable to add it interactively:
   vercel env add SUPABASE_URL production
   vercel env add SUPABASE_KEY production
   vercel env add PORT production
   vercel env add SESSION_SECRET production
   vercel env add JWT_SECRET production
   vercel env add ADMIN_PASSWORD production
   vercel env add CORS_ALLOWED production
   vercel env add NODE_ENV production

REST API alternative (non-interactive — requires Vercel token and projectId):
curl -X POST "https://api.vercel.com/v9/projects/<PROJECT_ID>/env" \
  -H "Authorization: Bearer $VERCEL_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"key":"SUPABASE_URL","value":"https://rceyebgawmhrqpofxysp.supabase.co","target":["production"]}'

Repeat the REST call for each variable.

After adding variables, redeploy (or run `vercel --prod`).
